## 在 Mac 上跑预览前要改的一处

Mac 上的 place_orders.py 仍指向旧文件 today_plan_2026-10-08.json（信号日 10/7）。把本目录的 today_plan_2026-10-09.json 放到 ~/workspace/quant-practice/ 后，二选一：
1. 把 place_orders.py 里 PLAN_FILE 改为 "today_plan_2026-10-09.json"；或
2. 先备份旧文件，再用新文件覆盖同名文件。

然后：启动 IB Gateway（纸账户登录）→ 先只跑 `python3 place_orders.py` 预览（只读连接，不发单）→ 核对净值缩放与订单表 → 需要真发时再去掉 Gateway 的 Read-Only API 勾选并加 --execute，终端手动输入 YES 才发送。
