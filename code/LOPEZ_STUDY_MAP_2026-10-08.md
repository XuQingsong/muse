# 《金融机器学习的进展》× 你的中低频项目：对照学习笔记（2026-10-08）

用途：你明确不做高频，本笔记只挑与现有 v18 / PIT 验证直接相关的概念，跳过订单簿、imbalance bars、超算等日内内容。所有概念均用自己的话概括，不摘录原文。

## 一、先认你现在的方法在哪一档

你目前的验证习惯（见 FRAMEWORK_V3.md、signal_validation_report.md）：
- PIT 按申报日截断（financial_facts.filed <= asof_date），月末回算三本账 2,625 个截面；
- 固定 21/63 日相对 SPY 超额 + Spearman IC，分 2019-2022 / 2023-2026 两段看同向；
- 改规则一次只动一条（A–E 已验完，v18 定版），要求两段同向才保留。

这已经避开了最粗的前视偏差。书里对这套做法的主要增量在三处：试错次数的惩罚、标签定义、训练/测试隔离方式。

## 二、四组概念与你的对应物

1. 试错惩罚（对应：你试过 v10–v18 与 A–E 五条）
   - 核心想法：同一段历史试的变体越多，挑出的最好夏普越可能是运气；需要按尝试次数把夏普打折，并估计「回测本身过拟合」的概率。
   - 对你：给 v14→v18 的收益差（+45.26%→+49.45%）补一个「试了多少条规则」的折扣视角，避免把单窗口、单恐慌簇的结果当稳健结论。你已在 FRAMEWORK_V10.md 里写明该局限，这一步是把它量化。

2. 三重障碍标签（对应：你现在的固定 21/63 日超额）
   - 核心想法：不问「N 天后涨没涨」，而问价格先碰上障碍、先碰下障碍、还是先到期；上下障碍可按波动设定。
   - 对你：与你的分级卖出（警戒→破位→逻辑死亡）天然同构。signal_validation_report.md 里的内部人买入 21/63 日中位超额（+2.43%/+7.00%，高管 +9.59%）若换成障碍标签，能更贴近真实持有体验。适合做一个小样本对照实验，不必推翻现有 IC 体系。

3. 元标签（对应：你的成长确定性分 → 首笔比例 22%–70%）
   - 核心想法：主规则管方向，第二个判断只管「下不下、下多大」。
   - 对你：你已手工实现了这个分工（确定性计点 + 内部人 ×1.2/×1.35）。读书时重点看它对误报率/仓位的讨论，用来校准确定性分档，而不是另起模型。

4. 带剔除的交叉验证（对应：你的两段同向检查）
   - 核心想法：时间序列不能随机切分；测试段附近与之信息重叠的训练样本要剔除，并留隔离带，再组合轮换。
   - 对你：pit_book_scores 已有 2019-06~2026-08 月末截面，下一步若做 2021–2023 样本外回放，应按此口径切分，而不是简单前后对半。你的两段检查可视为其简化版。

低优先：分数阶差分（水平量如毛利率、估值倍数不要无脑差分，你已保留水平分，暂可略读）；层次风险平价（与你 30/30/40 分层预算同思想，看组合层时再读）。

## 三、建议阅读顺序（按对当前项目的边际收益）

1. 回测过拟合与试错惩罚 —— 先给 v18 结论加上「试错折扣」的自我审查；
2. 三重障碍 + 元标签 —— 直接映射你的卖出分级与确定性仓位；
3. 带剔除的交叉验证 —— 为样本外回放（尤其缺失的阴跌年）做准备；
其余章节按需查阅即可，微观结构部分可跳过。

## 四、一个可立即动手的小练习（用现有库，不新增数据）

- 数据：research.pit_book_scores（2,625 行）+ data.prices_daily；
- 做法：选内部人买入事件子集，对同一批事件分别用（a）固定 63 日超额、（b）按个股波动设上下障碍的标签，比较两者的胜率与中位结果是否同向；
- 验收：只看方向与量级是否一致，不以此改 v18 规则；样本仍受 30 只赢家池限制，结论只作方法对照。
