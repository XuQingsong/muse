# 因子框架 v3 研究说明（2026-10-07）

## 为什么重做

旧版把趋势、动量、基本面等因子近似等权相加，最后只给一个总分。问题不是因子数量，而是结构：重要性不同的因子互相抵消，致命问题可以被其他高分盖住，且看不出结论到底由什么驱动。本版改成：

1. **先过红线**：触发趋势破位、现金流与增长同时恶化、高估值遇增长减速、短线极端过热等条件时，直接封顶结论；
2. **再看四本账**：公司质量、成长与预期、估值、入场时机，分别 0-100，不合成“可买总分”；
3. **权重只作先验**：按公司类型说明哪本账更重要。权重尚未被基本面历史数据验证，不能说成科学最优；
4. **输出证据链**：列出主要支持、主要反对、组合关系、数据缺失和结论反转条件。

## 已验证到什么程度

对 10 只事后挑选的知名股票（AAPL、MSFT、NVDA、MRVL、TSLA、VST、AVGO、META、AMZN、GOOGL），用 2023-01-17 至 2026-06-24 的 420 个截面做了技术因子回看（每 21 个交易日取样，之后 21/63 个交易日相对 SPY 超额）：

- 旧总分与之后 63 日超额的 Spearman 相关约 **-0.109**；高分组之后 63 日平均超额 **+5.84%**，低分组 **+10.25%**。也就是说，旧总分在这个样本里没有显示“分越高越该买”，甚至方向相反。
- 单项技术因子里，252 日回撤的 IC63 约 **-0.183**：越接近 252 日高点，后续相对表现反而越弱；距 50 日线、3 个月动量、量比的 IC63 也多为负或接近 0。结论：这些技术指标更适合做**入场位置与风险闸门**，不适合包装成收益预测器。
- 样本有幸存者偏差、截面重叠、样本量小，以上只是方向性证据，不是策略有效性证明。

基本面因子本轮没有做历史有效性验证：SEC 当前接口返回的是最新修订口径，直接拿来回测会产生前视偏差。要验证质量/成长/估值账，必须另建 point-in-time 财报数据集（按 filing date 对齐）。在这之前，基本面权重只能标为“暂定先验”。

- **质量账：无效。** 63 日 IC 全期 -0.016（两段 -0.001/-0.036）；高分组中位

  均为负。质量只适合做风险背景，不预测超额。
- **成长账：总分无效，但内部有一项真信号。** 总分 IC +0.005 且两段反向；
  单项里营收增速加速度 rev_accel +0.093（+0.146/+0.045，两段同向最强），
  被 EPS 增速 -0.051（高增长后续不占优）拖累。毛利率变化近段 +0.073。
- **估值账：弱有效，唯一达标。** IC +0.064（+0.105/+0.036 两段同向）；
  高分组（便宜）63 日中位 +1.56% vs 低分组 -0.71%，价差 2.27pp。单项：
  PS 原始 -0.073、PEG 近似 -0.059、PE -0.042，均指向"贵的不占优"。

结论：在本池（30 只赢家池，仍有幸存者偏差）与本口径下，三本账现行权重
不成立。建议调整（用户 2026-10-08 拍板：先不动框架、结论留档，权重维持暂定先验，下同）：估值账保留方向可略升权；成长账剔除或
大降 EPS 增速、以营收加速度为核心；质量账降级为风险背景/红线素材，
不作选股预测。IC 量级 0.05-0.10 属弱信号，只够倾斜不够触发。
