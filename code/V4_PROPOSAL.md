# 纸面模拟 v4 改法预备稿（待用户拍板，不先跑）

背景：v3（30/30/40）收益 +8.03%、最大回撤 -2.43%，但平均仓位只有 31.1%、期末现金 447,083 美元（44.7%）。钱没投出去的两个瓶颈，v3 报告和交易表都能对上：

## 瓶颈一：进攻层几乎没用上 40% 的预算
- 192 个交易日里，进攻层只动过两只票：MRVL 三次试仓（每次约 1.75 万美元，占总权益仅约 1.8%，进攻单票上限是 8%）、CRM 九月才进场。
- 原因在脚本里可查（paper_trade_v3.py 第 29 行）：四本账门槛对三层一刀切，估值账 ≥45。进攻层标的（高波动/超高成长）估值账大多在 45 以下，信号根本过不了线，40% 预算长期闲置。
- 拟改：进攻层用独立门槛——估值账下限降到 35（与 EXIT_MIN 的估值退出线一致），或改为"估值不触发红线即可入场"，靠 8% 单票上限和分级减仓控风险，而不是靠估值门槛把人挡在门外。

## 瓶颈二：成长确定性把 MRVL 这类票判太低
- MRVL 三次试仓理由都是同一句"成长确定性低，首笔22%"（质量69/成长71/估值45/时机61-62），每次约 1.75 万美元，两三天后被警戒线清掉，来回三次净赚约几百美元。
- 判定逻辑（paper_trade_v3.py 第 55-65 行）：成长账 71 分只得 0 分（要 72 才得 1 分），再叠加增速减速 −1 分，直接落到"低"。即增速从极高位回落一点，就被当成不确定。
- 拟改：减速惩罚加条件——营收增速仍 ≥30% 且成长账 ≥70 时，减速只扣 0 分不扣 −1；或把成长账得分档从 72/85 改为 68/82，让 71 分至少得 1 分。MRVL 这种"高增速、轻微减速"的票应判"中"，首笔从 22% 提到进攻层基准 30%。

## 顺带建议加一个诊断输出
v4 跑的时候把"过了选股线但被仓位层门槛挡下"的信号单独记一份清单（哪只、哪天、卡在哪本账），这样下一轮调参不用再猜。

## 不动的部分
分层比例 30/30/40、单票上限、三级买卖、黑天鹅条款、回撤刹车全部保持，与 v1/v2/v3 同口径可比。
