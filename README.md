## 关键口径（网页必须遵守）

- 只读展示，**不要加下单功能**；金额单位美元（USD）。
- VIX 恐慌闸门、进攻层 -40% 灾难止损仅属 v18 回测，`paper_tracker` 前向未启用。
- 基本面持有分上限 90（不是 100）；"流动比率<0.8→只观察"与"PE>80→等价格"目前仅提示、不拦截新开。
- PLTR 在 10/9 重扫中因过热（RSI>80 且距 MA50>+15%）被剔出新开名单，但跟踪组合继续持有，不是卖出信号。
- 图表价格线为未复权价；用 adj_close 画图时成本/止损/止盈三线须按 (adj_close/close) 换算。
- v18 回测第一笔买入：2026-01-05 开盘（模拟，非真实交易）；前向跟踪 10 只持仓记账日 2026-10-09，逐日结算自 2026-10-12 起。
